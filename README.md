## ✨ What This Project Does

Need for Speed: Carbon is a classic arcade racer built for computers from a previous era. Those old programs were written for a type of processor that modern Macs no longer use, which is why the game normally refuses to start or runs poorly through workarounds.

Static recompilation solves this by converting the original machine instructions into instructions your current computer understands ahead of time — before you ever press Play. The result is a build that behaves like a normal application: you double-click it, it opens, and the game runs at full speed with your keyboard, mouse, or controller.

Because the game files themselves are copyrighted, they are not included here. You supply your own legitimate copy of Need for Speed: Carbon for PC, and nfs-carbon-mac uses those files to run the game. That is what "bring your own game" means.

## 🧰 Troubleshooting

**The application will not open.** Make sure you extracted the archive fully before running anything. Running an application from inside a compressed file is the most common cause of this problem.

**The game starts but the screen is black.** Switch to windowed mode using the in-game options or the application's launcher settings, then set a resolution your display supports.

**Your controller is not detected.** Connect the controller before launching the application, then open the controls menu and reassign the buttons manually.

**Performance feels uneven.** Close background programs that use a lot of graphics memory, such as browsers with many tabs open, and make sure your graphics driver is current.

**Progress is not saving.** Confirm the application folder is somewhere your user account can write to — your Documents folder is always a safe choice.

**Windows shows a security prompt.** This is a standard warning for newly published software. Choose the option to keep and run the file, then continue.
